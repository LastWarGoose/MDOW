# Ручные проверки перед выпуском

Этот список фиксирует ещё необходимые проверки и не означает, что они выполнены.

- [ ] Запустить каталог сборки на чистой Windows 10/11 без Python и среды разработчика.
- [ ] Проверить понятное сообщение при отсутствии FFmpeg/ffprobe, затем установить их.
- [ ] Проверить импорт MP3, WAV, FLAC и M4A; слушать начало, середину и конец результата.
- [ ] Скачать один ролик, для которого есть законное основание именно такого способа
  получения, с учётом условий сервиса. Зафиксировать источник, основание и версии инструментов.
- [ ] Во время загрузки изменить название/исполнителя/текст; убедиться, что они не сбросились.
- [ ] Проверить запрет плейлиста, текущей трансляции и ролика с ограничением доступа.
- [ ] Проверить отмену проверки, загрузки, конвертации и сохранения, отсутствие частичных файлов.
- [ ] Проверить отказ записи, нехватку места, конфликт имени, очень длинный путь.
- [ ] Открыть сохранённый файл в Windows Media Player и VLC: звук, кириллица,
  обложка; для USLT использовать режим/расширение проигрывателя с поддержкой этого тега.
- [ ] Заменить и затем удалить все пять тегов; повторно открыть файл в MDOW.
- [ ] Проверить крупный шрифт и масштаб Windows 125%, 150%, 200%.
- [ ] Проверить лицензии поставляемых компонентов и наличие необходимых уведомлений/исходников.
